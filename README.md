# Claude API 中转站怎么选：避坑清单 + 自测脚本（2026）

国内直接用 Anthropic 官方 API，要过支付、KYC、封号三关，所以很多人用中转站。中转站的问题是水很深：便宜的可能掺了别的模型，看着便宜的可能在缓存和 token 计数上多收，有的站用两个月就跑路了。

这个仓库不推荐具体站点，只干两件事：

1. 一份**选站清单**，列出充值前该看哪几项；
2. 一个**自测脚本** [`check_relay.py`](check_relay.py)，拿到任何一个站的 Key，几分钟测出首字延迟、token 计数和缓存是否真的生效。

## 一、充值前看这 6 项

**1. 模型是不是真的**

低价站常见的做法：用户请求 Opus，后端转给便宜模型或国产模型。只问模型「你是谁」没用，模型自报身份可以被 system prompt 改掉。比较靠谱的办法：

- 同一段固定文本，同一个 Claude 模型算出的 `usage.input_tokens` 是固定的。有些渠道转发时会附带少量标识，多出几十个 token 不一定有问题；但差出几百上千，或者和别的站差距悬殊，就要怀疑后面换了模型或被塞了大段 system prompt。脚本里的「计数测试」就是测这个。
- 拿你手上真实的难任务（大仓库重构、长链路 debug）跑一遍，对比官方渠道或你信得过的渠道。体感差距通常一两次就能看出来。

**2. 缓存有没有真的生效、按什么价格算**

Claude Code 这类工具每轮都带大段上下文，缓存命中率决定了你实际花多少钱。要看两点：

- 第二次发相同前缀，返回里 `cache_read_input_tokens` 是否大于 0。有的站根本没开缓存，全按原价输入算。
- 缓存读取的单价是不是按官方比例。官方价目表里缓存读远低于普通输入；有的站把缓存读按输入的 15%、30% 收，账面单价低，实际更贵。

**3. 账单能不能逐条查**

至少要能看到每次请求的模型、输入/输出/缓存 token 和扣费。只给一个总余额的站，哪天账单异常你也查不出原因。

**4. 速度**

看首字延迟（TTFT）和输出速度，晚高峰（20:00–23:00）再测一次。脚本会打印这两个数。

**5. 稳定性和跑路风险**

运营时间、有没有公开的状态页或用户群、出故障时有没有公告。不管哪家，**用多少充多少，不要大额预充**。

**6. 价格要算全**

对比时用「人民币/百万 token」，把输入、输出、缓存读、缓存写都算上。只看「几折」不够，因为各家折扣的基准不一样。

## 二、自测脚本

只依赖 Python 3 标准库，不用装任何包。

```bash
export RELAY_KEY=你的key
python3 check_relay.py --base-url https://某站域名 --model claude-sonnet-5-5
```

会跑三项：

| 测试 | 看什么 | 正常表现 |
|---|---|---|
| 流式延迟 | 首字延迟、总耗时、输出 token/s | 首字 1–3 秒内，晚高峰别差太多 |
| 计数 | 固定文本的 `input_tokens` | 同一模型、同一文本，各站应基本一致；把结果贴到 Issue 里可以横向对比 |
| 缓存 | 连发两次相同长前缀，第二次的 `cache_read_input_tokens` | 第二次大于 0 |

脚本每项测试都会真实扣费，一次全跑完大概几分钱到几毛钱（取决于模型）。

## 三、官方价格参考

对比各渠道价格时，先换算成和官方价的比例，再看缓存。以下为 Anthropic 官方价（美元 / 百万 token，核对于 2026-11-27）：

| 模型 | 输入 | 5 分钟缓存写 | 1 小时缓存写 | 缓存读 | 输出 |
|---|---|---|---|---|---|
| Claude Fable 5.2 | 8 | 10 | 16 | 0.20（0.025 倍） | 40 |
| Claude Opus 5.5 | 4 | 5 | 8 | 0.20（0.05 倍） | 20 |
| Claude Sonnet 5.5 | 2 | 2.50 | 4 | 0.10（0.05 倍） | 10 |
| Claude Haiku 5.5（≤10 万 token） | 0.10 | 0.125 | 0.20 | 0.01 | 0.50 |

规律：5 分钟缓存写 = 输入 × 1.25，1 小时缓存写 = 输入 × 2；缓存读大多数模型是输入 × 0.1，上表几款新模型更低。某个渠道的缓存读折算下来明显高于这个比例，就是在缓存上多收了。

缓存最小长度：Fable 5.2 / Opus 5.5 / Sonnet 5.5 / Haiku 5.5 等新模型 512 token，Opus 4.8 / Sonnet 5 / Sonnet 4.6 为 1024，Opus 4.7 为 2048，Opus 4.6 / Haiku 4.5 为 4096。低于最小长度不会缓存，也不报错。

来源：[Pricing](https://platform.claude.com/docs/en/about-claude/pricing)、[Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)。价格以官方页面为准。
